# ScholarZone 学术投稿助手

**中文 | [English](README.md)**

![ScholarZone](assets/promo-large.png)

ScholarZone 是一款面向科研人员的 Chrome 浏览器插件。它在 Google Scholar、PubMed、arXiv、知网和期刊官网等页面上直接显示期刊分区徽章(分区、影响因子、CCF 等级),自动追踪投稿状态,并订阅学术大牛的新论文。

**内置两套期刊数据库,完全离线可用、无需登录:**

- **新锐期刊分区表 2026** —— 中科院分区表永久停更后的接棒标准
- **JCR 2025** —— 影响因子与 Web of Science 分区

> 中科院文献情报中心已于 2026 年官宣永久停发期刊分区表(2025 为终版)。ScholarZone 是第一个、也是唯一以新锐分区 2026 为唯一分区标准的浏览器插件。

## 核心功能

- 🏷️ **全网期刊徽章** —— 新锐分区 2026、Top 标识、预警名单、JCR IF / 5 年 IF、JCI、CCF A/B/C、SSCI、EI、ABS/AJG、FT50、UTD24
- 🔍 **离线期刊检索** —— 21,772 条本地数据,支持模糊与缩写匹配(*JACS*、*Adv Mater*……)
- 🧹 **结果筛选** —— 按分区多选,隐藏 / 遮罩 / 高亮论文
- 📮 **投稿追踪** —— 自动识别投稿系统稿件状态,带时间线与通知
- 👤 **学术追踪** —— 关注学者,自动同步新论文
- ✅ **待办热力图看板**
- 📊 **Excel 导出** —— 支持按分区筛选

## 安装

**方式一 —— Chrome 应用商店**(新上架审核中):入口见官网
<https://chrome.tvt.wiki>。

**方式二 —— GitHub Releases**:
1. 在 [最新 Release](https://github.com/MicTx/scholarzone/releases) 下载
   `scholarzone-extension-store.zip`
2. 解压
3. 打开 `chrome://extensions`,开启**开发者模式**,点击**加载已解压的扩展程序**,选择解压后的文件夹
